# E-commerce Event Schema (Raw)

## Purpose
Stores append-only user interaction events generated by an e-commerce website.  
Each row represents a single action taken by a user at a specific point in time.

## Table: raw.events

### Columns

| Column | Type | Nullable | Why it exists |
|---|---|---:|---|
| event_id | UUID | No | Uniquely identifies each event |
| event_type | TEXT | No | Defines what action occurred |
| event_timestamp | TIMESTAMP | No | Orders events in time |
| user_id | INT | No | Identifies the user |
| session_id | UUID | No | Groups events into a single visit |
| page_url | TEXT | Yes | Page-level behavior analysis |
| product_id | INT | Yes | Product interaction tracking |
| category | TEXT | Yes | Enables category rollups |
| price | NUMERIC(10,2) | Yes | Revenue analysis |
| quantity | INT | Yes | Order sizing |
| device_type | TEXT | No | Device-based conversion analysis |
| traffic_source | TEXT | No | Marketing attribution |

## Rules
- Events are append-only
- `purchase` events must include `product_id`, `price`, `quantity`
- Non-product events may have null product fields
